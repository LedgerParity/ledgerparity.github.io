BROWSER-ONLY FORMAT CHECK

Check a payment export.

Catch common JSON shape, identity, amount, and time errors before you run the LedgerParity CLI.

Your data stays in this page. The checker has no upload or network code. Do not paste real customer data into shared or recorded browser sessions. This preflight is an early format check; the CLI remains authoritative.

Payment JSON

Paste one JSON array of canonical payment records. Amounts must be decimal strings; use "[]" for an empty export.

The input is limited to 256 KiB in this browser tool. Nothing is sent to a server.

Preflight result

Paste an export and choose “Check JSON.”

    What this check covers

    • Required payment fields, supported classic payment type, and known field names.
    • Positive decimal-string amounts with at most seven fractional digits and the signed int64 stroop limit.
    • Native XLM or complete classic credit-asset identity; contract tokens are rejected.
    • One valid timestamp or one ordered settlement interval.

    It does not fetch Stellar data, test whether a payment settled, compare records, establish export completeness, or produce evidence bundles. Continue with the CLI quick start for validation and reconciliation.
