# Security

This repository hosts static documentation only; it contains no application
code, keys, or secrets.

For a security concern about the LedgerParity projects:

- Use GitHub Security → **Report a vulnerability** on the affected repository
  (core, connectors, CLI) if private reporting is available.
- Otherwise open a minimal issue asking for a private contact without
  disclosing secrets, customer data, or exploit details.

No dedicated security mailbox or response-time promise has been established.
See each project repository's `SECURITY.md` for the trust model (read-only
design; provider data is trusted, not a verified proof; reports are sensitive
and must not be committed publicly).
